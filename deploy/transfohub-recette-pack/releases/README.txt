================================================================================
 Dossier RELEASES — ZIP de la nouvelle version TransfoHub
================================================================================

Déposez ici l'archive téléchargée depuis GitHub avant de lancer :

  sudo ../install-recette.sh

Exemple de nom de fichier :
  TransfoHub-main.zip
  TransfoHub-v0.4.0.zip

Téléchargement GitHub (depuis un poste autorisé) :
  https://github.com/Larbs77/TransfoHub/archive/refs/heads/main.zip

Puis copie sur le serveur :
  scp TransfoHub-main.zip root@SERVEUR:/root/scripts/transfohub-recette-pack/releases/

Le script listera les .zip présents et vous demandera lequel déployer
s'il y en a plusieurs.
